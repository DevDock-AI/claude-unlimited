Help
Every command claude-unlimited supports, run from a terminal
Getting started
claude-unlimited doctor
Copy
Checks your install, Keychain access, and configuration — run this first, and any time something seems off.
claude-unlimited add-account (alias: ac)
Copy
Opens your browser, logs into a Claude account through an isolated Claude Code session, and adds it as a Profile — the account UUID is always resolved automatically. Never affects any account already signed into `claude` on this machine, so it's safe to run again for each additional account.
claude-unlimited add-codex-account
Copy
Opens your browser, logs into a ChatGPT/Codex account through an isolated session, and adds it as a Profile routed through GPT models — mirrors add-account exactly. Never affects any account already signed into `codex` on this machine, so it's safe to run again for each additional account.
claude-unlimited reauth
Copy
Re-authenticates a Profile that needs it — defaults to whichever ones the daemon reports as "needs re-auth", and lets you pick if there's more than one. Logs back into the exact same account, never a new one.
claude-unlimited start [--port PORT]
Copy
Runs the daemon in this terminal (Ctrl-C to stop) — good for a first look before installing it as a background service. Default port 4317.
Everyday use
claude-unlimited code [--profile <name>] [-- claude args]
Copy
Starts the daemon if it isn't already running, then launches claude routed through your pool. Any extra arguments pass straight through to claude.
claude-unlimited status
Copy
Reports whether the daemon is installed as a background service and currently running, and its pid.
Background service
Auto-starting the daemon on login — the same thing Settings → Daemon controls
claude-unlimited install [--port PORT]
Copy
Registers the daemon to start automatically on login (launchd on macOS, systemd --user on Linux, Task Scheduler on Windows) and starts it now.
claude-unlimited uninstall
Copy
Stops the daemon from starting automatically on login.
claude-unlimited service-start
Copy
Starts the already-installed background daemon right now.
claude-unlimited service-stop
Copy
Stops the installed background daemon.
